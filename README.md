# Needed

**A manifesto for everyone with work left to do.**

📖 **Read it: <https://cti97.github.io/needed/>**

---

The text lives in [`index.md`](index.md). Edit that file, commit, and the
website rebuilds itself within a minute or two.

Needed is a movement for people whose work was displaced by AI, built on free
and open-weight models. The manifesto argues that intelligence has become
cheap, that organization has not, and that the useful response is to build real
tools for real people — and to own what you build.
